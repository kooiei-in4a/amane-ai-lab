# agents/

このディレクトリはAIエージェント運用ルールの詳細正本である。

入口は常にルートの `AGENTS.md` とする。

| パス | 内容 |
|---|---|
| `policies/` | 公開安全性、正本権限、引用、完全性などの方針 |
| `roles/` | 役割別の観点 |
| `workflows/` | 作業手順 |
| `prompts/` | 再利用プロンプト断片 |
| `schemas/` | JSON Schema |
| `checklists/` | 公開前チェック |
| `examples/` | 入力例 |

同じルールを複数ファイルへコピーしない。必要なら参照リンクを置く。
