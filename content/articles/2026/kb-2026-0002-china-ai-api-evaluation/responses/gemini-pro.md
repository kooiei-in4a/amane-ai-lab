# Gemini Pro回答（公開用編集版）

> **完全性:** edited  
> 原回答は、主要モデルの比較表、課金条件、人気・話題性、モデル別詳細、用途別推奨を含む調査レポートです。公開用には主要な判断と注意点を残し、重複する表と時点依存の細かな数値を整理しました。モデル名・価格・契約条件は一次情報で再確認が必要です。

## エグゼクティブサマリー

Gemini Pro回答は、DeepSeek、Qwen、GLM、Kimiを主要候補として評価しました。

主な判断は次の通りです。

1. **総合候補:** DeepSeekの高性能系列とQwenの上位系列。
2. **コーディング:** DeepSeekとGLMを有力視。
3. **AIエージェント:** QwenとGLMをTool Calling、長文脈の候補として評価。
4. **低価格:** DeepSeekの高速・低価格系列。
5. **日本からの利用:** 公式APIより、OpenRouterやSiliconFlowなどの第三者APIを使うと摩擦が少ない。
6. **人気:** DeepSeek系列。
7. **話題性:** Kimiの新しい巨大モデル。
8. **リスク:** 中国国内向けAPIの契約要件、データ移転、API安定性。

## モデル別の位置づけ

### DeepSeek

- 価格性能比が高い主力候補
- 複雑な修正や複数ファイル変更に向くと評価
- 低価格系列はバッチや補助タスク向け
- 公式APIの混雑、Cursor固有機能との相性、データ条件を注意点とする

### Qwen

- 日本語と多言語性能を高く評価
- OpenAI互換APIとエージェント用途の候補
- 長い入力では段階料金が変わる可能性を指摘
- OpenRouter経由が簡単とする

### GLM

- コーディング特化、長いコンテキスト、長時間エージェントの候補
- Tool Callingと大規模リポジトリ解析を評価
- 日本からは第三者API経由が使いやすいとする
- 公式価格と契約条件の確認が必要

### Kimi

- 巨大なモデル規模と長文脈で話題性が高い
- 高難度タスクや巨大リポジトリ向け
- 他候補より出力単価が高く、大量処理には不向き

## 推奨順位の考え方

回答は、用途別に順位を分けています。

| 用途 | 上位候補 |
| --- | --- |
| 総合 | DeepSeek、Qwen、GLM |
| コーディング | GLM、Qwen、DeepSeek |
| AIエージェント | DeepSeek、Qwen |
| 低価格 | DeepSeekの低価格系列 |
| 日本からの直接契約 | DeepSeekを高く評価 |
| 機密性 | オープンウェイトのセルフホストを候補化 |

ただし、機密性については、セルフホストの設備・運用負担を別途考慮する必要があります。

## Cursorと開発ツール

Gemini Pro回答は、OpenAI互換エンドポイントを使い、CursorのCustom ModelやBase URL設定、またはClineなどの拡張から利用できると評価しています。

一方で、reasoning固有フィールドの表示やComposer機能には制約があり得るとしています。

## API検証

上位候補に対して、次の課題を同じ条件で実施することを提案しています。

- 関数生成
- バグ修正
- 複数ファイル変更
- コードレビュー
- テスト生成
- 日本語仕様書からの実装
- Tool Calling
- JSON Schema
- 日本語指示
- 大規模リポジトリ理解

評価項目は、タスク達成、指示遵守、コード品質、応答時間、費用、キャッシュ効果、修正回数です。

## 最終提案

Gemini Pro回答は、DeepSeek、Qwen、GLMを最初のAPI検証候補とし、Kimiを高難度・高価格の比較枠に置いています。

また、複数モデルを統一APIで比較できる第三者APIを初期導入に推奨しています。ただし、公式APIの契約容易性やデータ管理については、他回答と食い違う項目が残っています。
