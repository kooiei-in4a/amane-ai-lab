# Gemini思考回答（公開用編集版）

> **完全性:** edited  
> 原回答は、DeepSeek、Qwen、Kimi、GLM、MiniMax、Doubao、Hunyuan、Yiなどを対象に、比較表、契約条件、採点、API検証計画を提示した調査レポートです。公開用には中心的な主張を維持し、長大なモデル別詳細と重複表を整理しました。具体的な数値と契約条件は一次情報で再確認が必要です。

## 調査対象と除外

Gemini思考回答は、次を主要対象に含めました。

- DeepSeek
- Alibaba Cloud / Qwen
- Moonshot AI / Kimi
- Zhipu AI / GLM
- MiniMax
- ByteDance / Doubao
- Tencent / Hunyuan

## エグゼクティブサマリー

主な判断は次の通りです。

1. **有力な系列:** DeepSeekとQwen。
2. **コーディング:** Qwenのコード特化モデルとDeepSeekの高性能モデル。
3. **AIエージェント:** DeepSeek、Kimi、GLM。
4. **低価格:** DeepSeekの低価格系列と中国国内の低価格モデル。
5. **日本からの契約:** OpenRouterやAlibaba Cloud International。
6. **人気:** DeepSeekとQwen。
7. **話題性:** DeepSeekの新世代とKimi。
8. **API経路:** 中国国内向け公式APIより、国際第三者Providerを第一候補とする。
9. **主要リスク:** データ移転、学習・ログ、可用性、急な仕様変更。
10. **開発ツール:** OpenAI互換APIを使い、Cursor周辺やClineから利用可能と評価。

## モデルの役割

### DeepSeek

- 複雑なリファクタリングと複数ファイル変更
- ReasoningとTool Calling
- 低価格なシステム組み込み
- 公式APIの混雑とレート制限を注意点とする

### Qwenのコード特化モデル

- 単体関数、アルゴリズム、テスト生成
- オープンウェイトとセルフホスト
- 日本語を含む多言語
- 長大なコンテキストでの指示追従を注意点とする

### Kimi

- 長い資料や大規模コードベース
- 長時間の自律タスク
- 公式直販より第三者API経由を推奨
- 価格が高いことを注意点とする

### GLM

- Tool Callingを多用する業務エージェント
- Web検索や外部APIを伴う複合タスク
- Z.ai海外版または第三者APIを候補とする
- 公式価格と契約経路の確認が必要

### その他

MiniMaxは長文解析、Doubaoは中国国内の低価格利用、Hunyuanは業務組み込み、Yiは高速軽量用途の候補として扱いました。ただし、日本からの契約容易性や世代の新しさによって優先度を下げています。

## 検証計画

次の10課題を共通テストとしています。

1. 単一関数生成
2. バグ修正
3. 複数ファイル変更計画
4. セキュリティを含むコードレビュー
5. 単体テスト生成
6. OpenAPIなど仕様からの実装
7. Parallel Tool Calling
8. JSON Schema
9. 日本語業務ロジック
10. 長いリポジトリ理解

結果には、成功、指示遵守、コード品質、実行可能性、応答速度、トークン数、費用、修正量を記録します。

## データと契約

回答は、次の対策を提案しています。

- 機密情報を匿名化・マスキングする
- ZDR条件が明確なProviderを選ぶ
- オープンウェイトを自社環境または管理可能なクラウドで動かす
- 公式APIと第三者APIを別に評価する
- 中国国内向けと海外向けサービスを分ける

## 最終提案

最初のAPI検証では、DeepSeek、Qwenのコード特化モデル、GLMを中心にし、Kimiを高難度比較へ加える構成を提案しています。

日本からの利用では、OpenRouterやAlibaba Cloud Internationalなどの国際経路を優先し、機密コードについてはProviderのデータ条件またはセルフホストを再評価する方針です。
