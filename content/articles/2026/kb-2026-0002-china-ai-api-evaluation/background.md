# 検討に至った背景

## なぜこの調査を行ったのか

中国企業・中国系研究組織が開発するAIモデルは、低価格、長いコンテキスト、コーディング性能、オープンウェイトなどを理由に、開発用途の候補として扱われることが増えています。一方、日本から実務で使う場合は、性能ランキングだけでは判断できません。

実際の導入では、次の条件が同時に成立する必要があります。

- 日本の個人または法人が契約・決済できる
- APIを既存プログラムや開発ツールへ接続できる
- Tool Callingや構造化出力が安定して動く
- 価格と応答性能が業務量に見合う
- 入力したソースコードや業務情報の保存・学習・移転条件を説明できる
- モデル更新や提供終了に備えて再現性を確保できる

このため、単なるベンチマーク順位ではなく、「日本から現実的に導入できるか」を中心に複数のAIへ同じ調査を依頼しました。

## 今回の中心的な問い

中心的な問いは、次の2つです。

1. 提供された3つのAI調査から、どの中国製AIモデルを導入候補として残せるか
2. 回答間の矛盾や未確認情報がある状態で、どこまで結論を出してよいか

公開後の2026-08-01追記は、「個人のコーディング用途で、いま試す現行モデルIDはどれか」に答える追加確認です。調査時点の慎重な法人導入判断を置き換えるものではありません。

## 入力資料の構成

今回の入力は、主たる調査プロンプト、ChatGPTの回答1件、Geminiの回答2件、3回答の純粋マージ、統合要約、矛盾点レビューで構成されています。

| 役割 | 採用した資料 | 記事での扱い |
| --- | --- | --- |
| 調査条件 | 主たる調査プロンプト | `prompt.txt` の正本 |
| AI回答 | ChatGPT回答 | 独立した編集版回答 |
| AI回答 | Gemini Pro回答 | 独立した編集版回答 |
| AI回答 | Gemini思考回答 | 独立した編集版回答 |
| 詳細統合 | 3結果の純粋マージ | 分析の基礎資料 |
| レビュー | 明らかな矛盾点 | 不確実性と停止条件の基礎資料 |
| 圧縮版 | 3結果の統合要約 | 結論構成の補助資料 |

統合要約は純粋マージの派生資料であり、独立したAI回答としては数えていません。矛盾点一覧も新しい調査回答ではなく、3回答を比較したレビューとして扱います。

2026-08-01の個人開発向け追記とコーディング再比較は、上記3調査の入力には含まれません。結論本文（`conclusion.md` / `conclusion-plain.md`）へ後から足した公開後確認であり、元のAI回答や純粋マージを書き換えた正本ではありません。

## 対象範囲

対象は、API経由で利用でき、次の用途に関係する中国製AIモデルです。

- コード生成、修正、レビュー、テスト生成
- Cline、Roo Code、Continueなどの開発エージェント
- 独自のAIエージェントや業務システムへの組み込み
- 低価格な大量処理
- 長い仕様書やリポジトリの解析
- 日本からの契約、決済、運用

## 対象外

次は今回の記事では確定しません。

- 各モデルの絶対的な性能順位
- 日本発行カードが実際に承認されるか
- 個別アカウントの本人確認結果
- 契約書、DPA、ZDR、保存期間の法的評価
- 実APIを使った速度、障害率、Tool Calling成功率
- セルフホストに必要な正確な設備費
- 2026-08-01追記で名前を挙げた一部モデル以外の価格・モデル更新、および今後の変更

名前を挙げた中国製モデルについては、2026-08-01の追記で公開価格やモデルIDを再確認しています。それ以外のモデル・Providerや、その後の更新は未確認のままです。

## 読み方

この記事は、根拠の異なる3層で読んでください。

1. **第1層（3調査の統合）:** 評価方法と中国製系列の候補群。単一の勝者は決めません。
2. **第2層（個人開発向け追記）:** DeepSeek／GLM／Kimiなど特定中国製モデルの一次情報による価格・接続整理。
3. **第3層（コーディング再比較）:** 公表ベンチマークとAPI従量単価によるCoding Agent向け再比較。費用・性能の文脈ではGPT-5.6やClaude Opus 5など中国製以外も含みます。

AI回答内のモデル名、料金、仕様、ランキングは、回答時点の調査結果または主張です。複数回答が一致しただけで事実認定せず、一次情報と実APIで再確認すべき項目を明確に分けます。後ろの追記は前の調査回答を上書きした正本ではなく、公開後の追加確認です。
