# KB-2026-0004 一般読者向け用語改善

## 目的

公開記事内の英語専門用語を、一般読者が本文だけで理解できる表記へ改善する。

## 対応方針

- 日本語だけで意味が通る箇所は日本語へ置換
- 正式評価名や判定コードは、一次資料との照合用に括弧内へ保持
- 初出時に短い説明を付与
- 記事正本、要約、TL;DR、正式結果表、公開生成物を同じ表記へ統一

## 主な対応

- Acceptance Criteria / AC → 受け入れ条件
- Review-only Agent → レビュー専任AI
- Fix Agent → 修正担当AI
- Hard fail → 重大失格
- Invalid → 無効
- payload → 送信内容
- BLOCKED_BY_APPROVAL → 承認待ち
- 9つの採点項目 → 日本語名、意味、正式英語名を併記
