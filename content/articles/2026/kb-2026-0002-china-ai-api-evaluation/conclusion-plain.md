# 結論を一言でいうと

## いま1社・1モデルに決めない

3つのAI調査は、DeepSeek、Qwen、GLMなどを有力候補として挙げました。しかし、値段、契約方法、一度に出力できる量、データの扱いについて、回答が大きく食い違っています。

そのため、今すぐ「このモデルが1位」と決めるのではなく、候補を役割別に残して少額の実験をするのが安全です。

## 推奨案

### 主力候補

安さとコーディング性能の候補として、DeepSeekの現行高性能モデルを試します。

### 日本企業向け候補

日本語、国際契約、リージョン、法人運用を重視し、Qwenの現行国際向けモデルを試します。資料に書かれた名称をそのまま使わず、公式ページで現在のモデルIDを確認します。

### 長時間エージェント候補

複数のツールを長く使う仕事では、GLMの現行モデルを比較します。ただし、値段と最大出力の記述が食い違うため、契約前に確認します。

### 安い大量処理

分類、前処理、簡単なレビューなどは、DeepSeekの低価格・高速モデルを比較します。

### 難しい仕事の比較枠

他モデルが失敗する難しい課題や大きなリポジトリでは、Kimiの現行高性能モデルを限定的に試します。高価になりやすいため、通常の大量処理には使いません。

## 進め方

1. 公式ページで、現在使える正確なモデル名と値段を確認する
2. OpenRouterなどで同じ課題を試し、候補を絞る
3. 本番で使う公式APIまたは固定Providerでもう一度試す
4. 顧客情報や非公開コードを送ってよい契約か確認する
5. 主力、安い補助、難しいレビュー、予備の4役に分ける

## メリット

- 誤ったランキングで契約する危険を減らせる
- 実際にかかる費用と人間の手直し時間を比べられる
- 1つのサービスが止まっても切り替えやすい
- 安いモデルと高性能モデルを使い分けられる
- セキュリティや契約条件を説明しやすい

## デメリット

- 比較試験の準備と記録に手間がかかる
- 複数のAPIキーや請求を管理する必要がある
- モデル更新が速く、定期的な再試験が必要になる
- 機密情報を扱う場合は、法務とセキュリティ確認が増える
- 最初から1位を決める方法より、決定まで時間がかかる

## 経営・営業の判断ポイント

値段の安さだけでなく、次を確認してください。

- 顧客との契約上、コードやデータを外部AIへ送ってよいか
- データがどの国で処理・保存されるか
- 問題発生時の連絡や保証があるか
- モデルが終了した時に切り替えられるか
- 人間の修正時間を含めても安いか
- 日本語の仕様や業務ルールを正しく扱えるか

## 最終判断

**PoCでは複数モデルを同じ条件で比較し、本番ではモデルID、Provider、データ条件を固定する。**

これが、今回の資料から導ける最も安全で実務的な結論です。


## 個人開発者向け追記（2026-08-01）

公開後に、個人開発の用途だけに絞って現行モデルの一次情報を再確認した派生結論です。元の3調査だけで正式モデルIDや料金を確定したものではありません。価格や上限は変わるため、採用前に公式ページで再確認してください。

### 5つの使い分け

1. **日常開発の標準：DeepSeek V4 Flash**
2. **難しい実装・設計：DeepSeek V4 Pro**
3. **毎日エージェントを大量に使う：GLM-5.2 Coding Plan**
4. **コード特化の比較・代替：Kimi K2.7 Code**
5. **非常に難しい課題だけ：Kimi K3**

特に有力なのは、Flashを通常モデル、Proを上位モデルとして切り替える構成です。同じDeepSeekのAPIキーとエンドポイントで使え、個人開発では費用を抑えやすいです。

### 費用感の目安

キャッシュなし・追加料金なしの仮定では、小規模タスク（入力10万／出力1万）でFlash約$0.017、Pro約$0.052、GLM-5.2約$0.18、Kimi K2.7 Code約$0.14、Kimi K3約$0.45です。大規模タスクではKimi K3がDeepSeek V4 Proの約8.6倍になりやすく、常用理由は限定的です。

### 推奨構成

#### 構成A（最も推奨）

通常はDeepSeek V4 Flash、難しい実装はV4 Pro、独立レビューはKimi K2.7 Code。

#### 構成B（定額で大量利用）

日常のCoding AgentはGLM-5.2 Coding Plan、重要な最終レビューはDeepSeek V4 Pro。まずはLiteを1か月試し、枠が不足したらProを検討します。

#### 構成C（高難度対応）

Flash → Pro → GLM-5.2 → Kimi K3 の順で段階的に上げます。

### 最終順位（個人開発）

1. DeepSeek V4 Pro／Flash
2. GLM-5.2
3. Kimi K2.7 Code
4. Kimi K3

**個人開発のコスト、実装品質、接続のしやすさを総合すると、DeepSeek V4 Flash／Proの組み合わせが第一候補です。** GLM-5.2は大量利用時の定額候補、Kimi K2.7 Codeはコード特化の代替、Kimi K3は高難度のスポット利用と位置付けるのが適切です。

法人導入、機密コード送信、日本カード承認、実API性能は、元記事の検証計画とセキュリティ・法務ゲートで確定してください。
